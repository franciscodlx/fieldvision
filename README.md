# FieldVision

Asistente técnico de campo con lentes **Ray-Ban Meta** y la IA de visión **Meta Muse Spark**.

La app vive en [`fieldvision/`](fieldvision/). Ahí está la guía para levantarla, las cuentas y
claves que hay que dar de alta, y la documentación:

➡️ **[fieldvision/README.md](fieldvision/README.md)**

```
fieldvision-build/
├── fieldvision/   ← app React Native (código, docs, iOS, Android)
├── docs/          ← especificación original del proyecto
├── PROMPT.md      ← prompt con el que se generó la primera versión
└── START.sh       ← script de esa generación inicial
```
